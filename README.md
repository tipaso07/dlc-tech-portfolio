# DLC Tech Portfolio

Portafolio profesional de Sebastián Gabriel Díaz De la Cruz, fundador de DLC TECH S.A.C.

## Tecnología

- Astro + TypeScript
- Tailwind CSS
- Markdown/MDX para proyectos

## Desarrollo local

```bash
npm install
npm run dev
```

`PROJECT_CONTEXT.md` se mantiene fuera del repositorio público: contiene notas privadas y no debe versionarse sin autorización explícita.
